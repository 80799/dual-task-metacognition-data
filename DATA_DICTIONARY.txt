DATA DICTIONARY

Manuscript: When Dual-Task Costs Extend to Metacognition: Evidence From Modality Overlap


1. General Coding

sub: Participant ID extracted from the raw filename. IDs are specific to each experiment.

age: Age in years, taken from the baseline file.

gender: Gender (Exp2–4), coded as 0 = female and 1 = male. Baseline records take priority, followed by visual and audio records.

Condition suffixes:
0 = baseline (single-task)
1 = visual (V–V)
2 = audio (V–A)

Accuracy and mean JOL are expressed on a 0–100 scale. Calibration and accuracy differences are expressed in percentage points. Gamma ranges from −1 to 1 when defined. Blank cells indicate missing or undefined values.

Derived measures are calculated from unrounded values and rounded to two decimal places.


2. Raw Data

Raw files are stored in the corresponding ExpN_raw_data folder.

Main-task files:
<ID>_baseline_data.csv
<ID>_visual_data.csv
<ID>_audio_data.csv

Main event types:
recognition: Recognition trial.
JOL: JOL trial (Exp2).
restudyChoice: JOL and restudy-choice trial (Exp3–4).
restudyDisplay: Re-presentation of a picture pair (Exp3–4).
interference: Distractor-task event.

Main fields:
cue, target: Cue and target picture filenames.
JOL_score: JOL rating (0–100).
restudy: 1 = selected for restudy; 0 = not selected.
participantResponse: Recognition response.
isCorrect: Recognition accuracy; 1 = correct, 0 = incorrect.
age, gender: Demographic information.
subject: Participant ID recorded by the task program.

CRT files:
<ID>_visualCRT.csv
<ID>_audioCRT.csv

CRT fields:
Trial: Trial number.
number: Presented digit.
corrANS: Correct response key.
response: Recorded response.
iscorrect: 1 = correct, 0 = incorrect.

Recognition accuracy = correct recognition trials / all recognition trials × 100.
CRT accuracy = correct CRT trials / all CRT trials × 100.
Trials with no CRT response remain in the denominator.


3. Exp1 Variables

sub, age: See Section 1.

acc0, acc1, acc2: Recognition accuracy in baseline, V–V, and V–A conditions.

CRT1, CRT2: CRT accuracy in the V–V and V–A conditions.


4. Exp2 Variables

sub, age, gender: See Section 1.

JOL0, JOL1, JOL2: Mean JOL in each condition.

acc0, acc1, acc2: Recognition accuracy in each condition.

corr_acc0, corr_acc1, corr_acc2: Chance-corrected recognition accuracy:
(acc − 25) / 0.75.

JOLCalibration0, JOLCalibration1, JOLCalibration2:
mean JOL − chance-corrected recognition accuracy.

gamma0, gamma1, gamma2:
Goodman–Kruskal gamma between item-level JOL and recognition correctness.

CRTacc1, CRTacc2:
CRT accuracy in the V–V and V–A conditions.

JOL and recognition records are matched within participant and condition using normalized cue filenames.


5. Exp3 Variables

sub, age, gender: See Section 1.

CRTacc1, CRTacc2: CRT accuracy in the V–V and V–A conditions.

restudy:
1 = selected for restudy; 0 = not selected.

display1:
Picture pair was re-presented during the restudy phase.

display0:
Picture pair was not re-presented during the restudy phase.

Display status is derived from restudyDisplay events. Picture pairs are matched using normalized cue and target filenames.

JOLCalibration0, JOLCalibration1, JOLCalibration2:
Calibration among display0 pairs:
mean JOL − (accuracy − 20) / 0.80.

JOLResolution0, JOLResolution1, JOLResolution2:
Goodman–Kruskal gamma between JOL and recognition correctness among display0 pairs.

JolChoiceGamma0, JolChoiceGamma1, JolChoiceGamma2:
Goodman–Kruskal gamma between JOL and restudy choice.

R1diffD0, R1diffD1, R1diffD2:
accuracy(display1 | restudy = 1) − accuracy(display0 | restudy = 1).

R0diffD0, R0diffD1, R0diffD2:
accuracy(display1 | restudy = 0) − accuracy(display0 | restudy = 0).

If either display group is empty, the corresponding difference is left blank.


6. Exp4 Variables

sub, age, gender: See Section 1.

CRT1, CRT2: CRT accuracy in the V–V and V–A conditions.

restudy:
1 = selected for restudy; 0 = not selected.

display1:
Picture pair was re-presented during the restudy phase.

display0:
Picture pair was not re-presented during the restudy phase.

Display status is derived from restudyDisplay events. Picture pairs are matched using normalized cue and target filenames.

JOLCalibration0, JOLCalibration1, JOLCalibration2:
Calibration among display0 pairs:
mean JOL − (accuracy − 20) / 0.80.

JOLResolution0, JOLResolution1, JOLResolution2:
Goodman–Kruskal gamma between JOL and recognition correctness among display0 pairs.

JolChoicegamma0, JolChoicegamma1, JolChoicegamma2:
Goodman–Kruskal gamma between JOL and restudy choice.

R1diffD0, R1diffD1, R1diffD2:
accuracy(display1 | restudy = 1) − accuracy(display0 | restudy = 1).

R0diffD0, R0diffD1, R0diffD2:
accuracy(display1 | restudy = 0) − accuracy(display0 | restudy = 0).

R1count0, R1count1, R1count2:
Number of picture pairs selected for restudy.

R0count0, R0count1, R0count2:
Number of picture pairs not selected for restudy.

If either display group is empty, the corresponding accuracy difference is left blank.


7. Goodman–Kruskal Gamma

gamma = (C − D) / (C + D),

where C and D are the numbers of concordant and discordant item pairs. Ties are excluded. If C + D = 0, gamma is left blank.

Gamma is calculated by the Python data-processing scripts.


8. Analysis Sample

filter: SPSS variable used to select the analysis sample. It is referenced in the Exp2–4 SPSS syntax but is not included in the CSV files generated by Python.

Exclusion criteria and final sample sizes are reported in the manuscript.
